# Учебные задания по веб-технологиям

Университетские задания по **WEBTE1 в FEI STU**, 2026/2027. Проекты показывают мою практику с HTML, CSS, JavaScript, браузерными API и обработкой структурированных данных из HTML.

## Избранные задания

| Проект | Основные возможности | Подробности |
| --- | --- | --- |
| **Na obed — меню ресторанов** | Fetch API, DOMParser, отдельные парсеры ресторанов, кеширование в localStorage и выбор дня/ресторана. | [README проекта](Z2_Liubotin/README.md) · [Исходники](Z2_Liubotin) |
| **Личный сайт** | Многостраничный сайт с резюме, стилями печати, расписанием, интерактивным изображением рабочего места и картой Leaflet. | [README проекта](Z1_Liubotin/README.md) · [Исходники](Z1_Liubotin) |

Небольшие практические упражнения находятся в каталогах `zadanie*`. Тексты сайтов остаются на словацком согласно требованиям курса.

## Локальный запуск

Из корня репозитория:

```bash
python3 -m http.server 8000
```

Затем откройте:

- Меню ресторанов: <http://localhost:8000/Z2_Liubotin/>
- Личный сайт: <http://localhost:8000/Z1_Liubotin/>

Используйте локальный HTTP-сервер вместо прямого открытия HTML-файлов: приложение меню загружает источники через Fetch API.

## Данные и зависимости

Приложение меню читает **сохранённые HTML-снимки** из включённого в проект каталога `source/`. Кнопка обновления заново обрабатывает эти файлы, а не скачивает актуальное меню ресторанов. После запуска локального сервера приложение может работать офлайн. Карта на личном сайте требует подключения к интернету.

Библиотеки и их лицензии описаны в README каждого проекта. Отчёты о валидации хранятся в каталогах `docs/` и описывают проверки соответствующих заданий.
