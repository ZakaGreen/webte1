# Как устроены Profil и Životopis

Этот разбор относится к текущим двум страницам. Читай его вместе с исходными файлами: сначала HTML, затем обычные стили, потом печать и JavaScript. Файлы `zadanie2`, `zadanie3` и `zadanie4` не изменялись.

## 1. Что делает каждый файл

| Файл | Задача |
| --- | --- |
| `index.html` | Содержание профиля: имя, рассказ о себе, три направления, девиз, контакты. |
| `pages/cv.html` | Содержание резюме: фотография, контакты, образование, опыт, навыки. |
| `css/styles.css` | Общее оформление обеих страниц, включая мобильный вид. |
| `css/print.css` | Изменения оформления CV при печати. |
| `js/script.js` | Открытие и закрытие мобильного меню. |
| `img/` | Обычная фотография и три предоставленные иллюстрации. |
| `fonts/` | Локальный шрифт Noto Serif и лицензия. |
| `favicon.png` | Значок IL во вкладке браузера. |
| `README.md` | Краткое описание проекта, источники и сведения об AI. |
| `docs/validator-html.txt`, `docs/validator-css.txt` | Ответы официальных валидаторов W3C. |

HTML описывает, **что находится на странице**. CSS задаёт, **как это выглядит**. JavaScript отвечает, **что происходит после нажатия кнопки**.

Для сайта не нужны npm, сборка, серверный код или база данных. Можно открыть `index.html` обычным браузером. Локальный HTTP-сервер удобен для проверки, но не является частью реализации.

## 2. Общая HTML-основа

```html
<!DOCTYPE html>
<html lang="sk">
  <head>
    ...
  </head>
  <body>
    ...
  </body>
</html>
```

- `<!DOCTYPE html>` включает стандартный режим отображения HTML.
- `html` — корневой элемент документа.
- `lang="sk"` сообщает, что язык содержимого — словацкий. Это полезно для озвучивания страницы и языковых инструментов браузера.
- `head` содержит служебную информацию.
- `body` содержит видимые элементы.
- Закрывающий тег, например `</body>`, завершает элемент. Вложенные элементы закрываются изнутри наружу.

### Что находится в head

`<meta charset="UTF-8" />` задаёт кодировку. Благодаря UTF-8 правильно отображаются словацкие буквы с диакритикой.

`<meta name="viewport" content="width=device-width, initial-scale=1.0" />` говорит мобильному браузеру использовать ширину устройства. Без него телефон может сначала нарисовать широкую настольную страницу, а потом уменьшить её целиком.

`title` — название HTML-документа. Оно отображается во вкладке браузера, закладках и часто в поисковой выдаче. Это не видимый заголовок страницы: заголовки внутри `body` создаются элементами `h1`–`h6`. На страницах `title` различается: `Profil | Ilia Liubotin` и `Životopis | Ilia Liubotin`.

`meta` хранит метаданные — служебные сведения о странице для браузера, поисковой системы или сервиса, в котором делятся ссылкой. Значение атрибута `content` само по себе не отображается внутри сайта. Если похожая фраза видна в середине страницы, она отдельно написана в `body`, например в элементе `p`.

```html
<!-- Description for search results -->
<meta name="description" content="Profil študenta aplikovanej informatiky Ilii Liubotina." />
```

`name="description"` обозначает краткое описание для поисковых систем. На каждой странице нужен только один такой элемент. По заданию описание должно соответствовать содержанию конкретной подстраницы, но точный текст и его длина не заданы.

Open Graph-поля управляют предварительным просмотром ссылки в мессенджере или социальной сети:

- `og:title` — заголовок карточки ссылки;
- `og:description` — краткий текст карточки;
- `og:image` — изображение карточки.

В Open Graph используется атрибут `property`, а текст или путь записывается в `content`. Эти метаданные не создают карточку внутри самой страницы. Задание требует все три поля на каждой подстранице. Сейчас в CV присутствуют все три, а в `index.html` отсутствует `og:image`; его нужно вернуть перед сдачей. Перед публикацией относительный путь изображения нужно заменить на полный URL школьного сервера. Реальный адрес сервера пока неизвестен.

Обычный рекомендуемый порядок внутри `head`: кодировка, `viewport`, `title`, описания, подключения через `link`, затем `script`. Большинство этих элементов браузер поймёт и в другом порядке, но `charset` принято ставить в начале.

### Как работают link и его атрибуты

```html
<link rel="icon" href="favicon.png" type="image/png" />
<link rel="stylesheet" href="css/styles.css" />
```

`link` связывает текущий документ с внешним ресурсом. `rel` сокращено от relationship и объясняет вид связи: `icon` означает значок страницы, а `stylesheet` — таблицу стилей. `href` содержит путь к ресурсу, `type="image/png"` — его формат. Порядок атрибутов внутри открывающего тега не меняет их смысл.

Favicon — общепринятое название маленького значка во вкладке браузера; слово произошло от favorite icon. Сам файл технически можно назвать иначе, потому что его роль задаёт `rel="icon"`. В этом проекте имя `favicon.png` понятно и совпадает с термином задания. По заданию favicon должен быть основан на том же мотиве, что и монограмма IL.

`link` — пустой элемент: он только указывает на ресурс и не содержит собственного текста, поэтому закрывающего `</link>` у него нет.

### Как читается подключение JavaScript

```html
<script src="js/script.js" defer></script>
```

`script` — название элемента. `src="js/script.js"` — его атрибут с путём к JavaScript-файлу. `src` сокращено от source. Атрибут `defer` не требует значения: само его присутствие означает, что файл можно загружать параллельно с чтением HTML, а выполнить нужно после разбора документа. К моменту `querySelector` кнопки и меню уже существуют.

Открывающий тег заканчивается первым символом `>`, после него сразу начинается закрывающий `</script>`. Между ними пусто, потому что код находится во внешнем файле. В отличие от `link`, элемент `script` парный, и закрывающий тег обязателен даже при наличии `src`.

Запись `<script><src="js/script.js" defer /></script>` была бы неправильной. `src` и `defer` — атрибуты, поэтому они находятся внутри открывающего тега `script`. Они не являются отдельными HTML-элементами. Кроме того, содержимое между `<script>` и `</script>` браузер воспринимает как JavaScript, и текст `<src=...>` вызвал бы ошибку.

Общий вид парного HTML-элемента:

```html
<tag attribute="value">content</tag>
```

HTML-комментарий записывается так:

```html
<!-- Short explanation in English -->
```

Комментарий не показывается как часть страницы, но его можно увидеть в исходном коде. По правилам задания комментарии в коде должны быть на английском языке и без диакритики. Комментарий полезен, когда кратко объясняет назначение неочевидной строки; повторять в нём очевидное название элемента не нужно.

Исходный HTML использовал запись пустых элементов с `/>`, поэтому она сохранена. В HTML5 этот слеш не закрывает отдельную пару тегов и не обязателен. W3C выдаёт информационные замечания к такому стилю, но ошибок валидации нет. Атрибуты у нас всегда в кавычках.

### Почему пути различаются

Из корневого `index.html` путь к CSS — `css/styles.css`. Файл CV находится внутри `pages/`, поэтому его путь — `../css/styles.css`.

`../` означает «подняться на один уровень вверх». Аналогично ссылка из профиля в CV — `pages/cv.html`, а обратно — `../index.html`.

Пути внутри CSS считаются **от CSS-файла**: `../img/me.jpg` означает выход из `css/` и переход в `img/`.

## 3. Общая шапка, меню и подвал

### Шапка

`header` объединяет монограмму IL, имя и одинаковый слоган. Монограмма — обычная ссылка с текстом и CSS-рамкой. Нажатие возвращает на профиль. Сложного рисования и отдельной графической библиотеки здесь нет.

`header` находится в `body` и обозначает видимую шапку страницы. `head` содержит служебные сведения, а `title` задаёт название документа во вкладке браузера.

В HTML названия элементов заданы стандартом: `a` — anchor (якорь, ссылка), `p` — paragraph (абзац). Это не типы данных и не названия, которые выбирает автор. В `<a ...>IL</a>` текст `IL` виден посетителю, `href` задаёт адрес перехода, а `aria-label` даёт ссылке понятное название для экранного диктора. Класс `monogram` задаёт оформление ссылки через CSS.

`class="site-header container"` присваивает элементу сразу два класса. `site-header` задаёт его расположение, а `container` — общую ширину и центрирование.

Контейнером называют элемент, который объединяет другие элементы. `div` — универсальный HTML-контейнер без специального смыслового назначения. Класс `.container` в CSS — отдельно выбранное название для правил ширины и центрирования. HTML создаёт элемент, а CSS оформляет его. Этот класс можно назначить `header`, `main` или `div`; использовать `div` и класс `container` вместе не обязательно.

Внутри шапки `div` объединяет имя и слоган. У `.site-header` стоит `display: flex`, поэтому его непосредственные потомки располагаются рядом: слева ссылка IL, справа общий блок имени и слогана. Внутри `div` абзацы идут друг под другом. Без этой обёртки ссылка, имя и слоган стали бы тремя отдельными элементами одного ряда. Сам `div` не обязателен по заданию, но нужен для текущего простого расположения.

### Меню

`nav` (navigation) обозначает область навигации — ссылки для перехода между страницами. Класс `site-nav` задаёт оформление меню, а `container` — ширину и центрирование. `aria-label="Hlavná navigácia"` называет эту область «Главная навигация» для экранного диктора; отдельный видимый заголовок из этого атрибута не появляется.

Внутри находится `ul` (unordered list), а каждая ссылка заключена в `li` (list item). Это ненумерованный список, даже если CSS убирает стандартные точки. Класс `nav-list` используется для оформления списка, а `id="nav-list"` — его уникальный идентификатор на странице. Совпадение названий класса и ID разрешено: это разные атрибуты с разными задачами.

```html
<a href="index.html" aria-current="page">Profil</a>
```

`href` — адрес перехода. `aria-current="page"` сообщает, что это текущая страница. CSS использует тот же атрибут для белой линии под пунктом. На странице CV этот атрибут стоит у ссылки `Životopis`.

Две существующие страницы связаны настоящими ссылками. Будущие три страницы пока не созданы и не добавлены в меню.

Кнопка `Menu` и список ссылок — соседние элементы внутри `nav`. Закрывающий `</button>` находится перед открывающим `<ul>`, поэтому ссылки не вложены в кнопку. `button` выполняет действие — раскрывает или сворачивает список, а каждый `a` переходит на страницу. `ul` объединяет ссылки в список, `li` обозначает отдельный пункт. Внешнее оформление ссылки может напоминать кнопку, но её HTML-элемент остаётся `a`.

На широком экране видны ссылки `Profil` и `Životopis`, а кнопка `Menu` скрыта. При ширине до 768 px включительно и работающем JavaScript видна кнопка `☰ Menu`, а список раскрывается после нажатия. Такое мобильное hamburger-меню требуется заданием.

Мобильная кнопка — настоящий `button`, поэтому Enter и пробел работают без самодельного обработчика клавиатуры. `type="button"` означает обычное действие, а не отправку формы.

- `aria-expanded="false"` сообщает экранному диктору, что управляемое меню свёрнуто. Когда меню открывается, скрипт меняет значение на `true`, а при закрытии возвращает `false`.
- `aria-controls="nav-list"` связывает кнопку со списком `<ul id="nav-list">`. Здесь записывается ID без символа `#`. Атрибут описывает связь, но сам не добавляет обработчик нажатия.
- `hidden` изначально скрывает саму кнопку, а не список ссылок. Это логический HTML-атрибут: его присутствие означает скрытие. Скрипт снимает его строкой `menuButton.hidden = false`, когда меню готово к работе. После этого CSS показывает кнопку только на узком экране; на широком она остаётся скрытой через `display: none`.
- `span` объединяет небольшой фрагмент текста внутри кнопки. Значок `☰` виден посетителю, но `aria-hidden="true"` исключает его из озвучивания: название кнопки уже дано словом `Menu`.

ARIA — атрибуты доступности. Они описывают название, состояние или связь элементов для вспомогательных программ. `aria-expanded` и `aria-controls` сами не открывают и не скрывают меню: видимость списка меняется через CSS-класс `is-open`, который переключает JavaScript. Без JS кнопка остаётся скрыта, а ссылки доступны.

Экранный диктор — программа для озвучивания страницы, например для пользователя с нарушением зрения. Его упоминание объясняет назначение ARIA; устанавливать или запускать его для понимания этих строк не требуется. В нашем CSS `aria-current="page"` дополнительно используется для подчёркивания текущей ссылки. Атрибут не переключается автоматически: в `index.html` он записан у `Profil`, а в `cv.html` — у `Životopis`.

### Ссылка пропуска

В начале `body` есть ссылка `Preskočiť na obsah`, ведущая на `#main`. Символ `#` указывает ID элемента на текущей странице. Обычно ссылка находится за левой границей экрана; при фокусе клавиатурой появляется сверху. Это позволяет перейти к содержимому, пропустив повторяющиеся шапку и меню.

### Подвал

`footer` содержит контакты и год. `address` обозначает контактную информацию, а не только почтовый адрес.

- `mailto:` предлагает открыть почтовое приложение.
- `tel:` предлагает позвонить через доступное приложение.
- Полный домашний адрес и дата рождения не опубликованы; указан город.

По просьбе автора ссылки на источники удалены из подвала; сведения об источниках остаются в README.md. Это отступление от требования задания о ссылках в подвале. Там оставлены контакты и год, без знака © и повторения имени.

## 4. Как устроен профиль

### Основное содержимое: main

```html
<main id="main" class="container">
```

Здесь три разные вещи: `main` — стандартный HTML-элемент основного содержимого страницы, `id="main"` — выбранный уникальный идентификатор, а `class="container"` — CSS-класс ширины и центрирования. Имя элемента и ID совпадают, но это не обязательно. Ссылка `href="#main"` в начале страницы ведёт именно к этому ID.

Внутри `main` находятся первый экран, рассказ о себе, интересы и девиз. Общие шапка, навигация и подвал расположены снаружи. `main` не требует отдельного CSS-правила, чтобы существовать: HTML задаёт структуру и смысл, а CSS подключается для нужного оформления. Этот элемент уже оформлен через класс `.container`.

В CSS селектор `main` выбирал бы элементы по названию тега, `#main` — элемент по ID, а `.container` — элементы по классу. Отсутствие правила `main { ... }` не означает, что элемент не используется.

### Первый экран

`section` — смысловой раздел страницы, обычно со своим заголовком. В отличие от универсального `div`, он обозначает группу содержимого на одну тему. В данном случае это представление автора; ниже отдельные `section` посвящены рассказу о себе и интересам.

```html
<section class="hero" aria-labelledby="profile-title">
```

`hero` — выбранное имя CSS-класса первого большого вводного блока. Это не HTML-тег и не обязательное название. Правило `.hero` задаёт фон, минимальную высоту и расположение содержимого. Запись `section.hero` означает «элемент section с классом hero».

Внутри `div` с классом `hero-text` объединяет короткую подпись, один `h1`, описание и ссылку на CV. CSS задаёт этому блоку ширину 44% и внутренние отступы, а на телефоне — ширину 100%. Класс `eyebrow` оформляет небольшую вводную подпись над главным заголовком: размер и цвет определены в CSS, сам `p` остаётся абзацем.

`h1` — главный заголовок страницы; он здесь один. `br` внутри имени принудительно переносит фамилию на следующую строку.

У `section` есть `aria-labelledby="profile-title"`: он указывает на `<h1 id="profile-title">`, текст которого служит названием раздела для вспомогательных программ. Это не кликабельная ссылка и не правило оформления. В отличие от `aria-label`, где название написано прямо в атрибуте, `aria-labelledby` берёт его из существующего элемента по ID.

Обычный `p` после заголовка содержит описание. `<a class="button" href="pages/cv.html">` переходит к CV. Класс `button` делает ссылку похожей на кнопку, но она остаётся элементом `a`, потому что выполняет переход. Вложенный `span` содержит декоративную стрелку `↗`; `aria-hidden="true"` исключает только стрелку из озвучивания, а не скрывает её на экране.

Рисунок подключён через CSS-фон. Он оформляет первый экран, а текст остаётся настоящим HTML: его можно выделить, найти поиском и прочитать экранным диктором. Это не текст, нарисованный поверх картинки в графическом редакторе.

У фоновой картинки нет атрибута `alt`; она декоративная. Ниже есть отдельная обычная фотография с `alt`, которая выполняет требование задания к изображению профиля.

`linear-gradient` немного затемняет левую часть фона. Это статичный CSS-градиент, чтобы белые линии рисунка не мешали читать текст. Портрет справа сохраняет яркость.

### Рассказ о себе

Раздел `about` содержит `h2`, фотографию и два абзаца. Первый посвящён учёбе, программированию и стажировке. Второй — чаю, путешествиям, инвестициям и цели развиваться.

```html
<img class="profile-photo" src="img/me.jpg"
     alt="Moja portrétna fotografia"
     width="850" height="1134" loading="lazy" />
```

- `src` указывает исходную фотографию.
- `alt` описывает изображение, если оно недоступно или страницу озвучивают.
- `width` и `height` задают исходные размеры и помогают заранее определить пропорции.
- `loading="lazy"` разрешает отложить загрузку изображения, пока оно не приблизится к видимой области.
- Размер на экране дополнительно задаётся CSS. Исходные атрибуты не заставляют фотографию всегда занимать 850 пикселей.

```css
.profile-photo {
  float: left;
  width: 150px;
  height: auto;
  margin: 0.4rem 1.8rem 1rem 0;
  filter: grayscale(100%);
}
```

`float: left` ставит фотографию слева и позволяет тексту обтекать её справа. Когда текст становится ниже фотографии, он снова занимает всю ширину. Это именно обтекание, которое требует задание.

`height: auto` сохраняет пропорции. Четыре значения `margin` идут по часовой стрелке: сверху, справа, снизу, слева. `grayscale(100%)` делает отображение чёрно-белым; исходный JPG не изменяется.

У родительского `.about` стоит `display: flow-root`. Он удерживает плавающее изображение внутри высоты раздела, даже если текст окажется короче фотографии. Это единственный небольшой вспомогательный приём для `float`.

### Три направления

`.interests` — обычный `ul` с тремя `li`. В каждом есть `h3` и пояснение. Направления: программирование и AI, чайная культура, экономика и инвестирование. Путешествия упомянуты в тексте о себе.

CSS Flexbox располагает три пункта рядом. `flex: 1` распределяет доступное пространство между ними поровну. На маленьком экране направление меняется на вертикальное.

### Девиз

`aside.motto` содержит связанный с твоими интересами дополнительный текст: «Čaj je pre mňa chvíľa pokoja». Это не приписанная другому человеку цитата. Фон — предоставленная чайная иллюстрация. Здесь нет интерактивных точек: они относятся к будущей отдельной странице задания.

## 5. Как устроено CV

После шапки и меню идёт `.page-heading`: название страницы и звёздный рисунок. Для печати используется Ctrl+P в браузере.

Главная часть — `.cv-layout` с двумя вложенными блоками:

```html
<div class="cv-layout">
  <div class="cv-sidebar">...</div>
  <div class="cv-content">...</div>
</div>
```

Слева находятся фотография, имя, контакты и короткий текст о путешествиях. Справа — образование, два места практического опыта, технические навыки, языки и дополнительные интересы.

Для смысловых разделов используется `section` с `h2`. Внутри рабочего опыта две самостоятельные записи оформлены как `article` с `h3`: стажировка и техническая поддержка.

`strong` выделяет значимую часть текста, например название языка и уровень. Списки навыков и языков сделаны обычными `ul`/`li`.

```css
.cv-layout {
  display: flex;
}

.cv-sidebar {
  width: 30%;
}

.cv-content {
  width: 70%;
}
```

`display: flex` ставит прямых потомков рядом. Их ширины составляют 30% и 70% родителя. При стандартном выравнивании Flexbox растягивает колонки по высоте до самой высокой. Поэтому фон левой колонки продолжается до конца правой, даже если текста слева меньше.

У колонок два разных оттенка чёрного. Их фон задан самим колонкам, а не отдельным абзацам. `float` в CV не применяется.

В CV сохранены точные уровни языков из исходного документа, включая различия между пониманием, письмом и разговором. Для трёх направлений указана практическая глубина опыта; выдуманных процентов, коммерческих клиентов или уровня «эксперт» нет.

## 6. Как читать общий CSS

### Правило состоит из селектора и свойств

```css
.site-name {
  margin: 0;
  font-size: 1.1rem;
}
```

`.site-name` выбирает элементы с этим классом. В фигурных скобках перечислены свойства. После имени свойства ставится двоеточие, после значения — точка с запятой.

| Запись | Что выбирается |
| --- | --- |
| `body` | Элемент по названию тега. |
| `.hero` | Все элементы класса `hero`. |
| `#nav-list` | Элемент с конкретным ID. |
| `h1, h2, h3` | Все перечисленные виды элементов. Запятая объединяет независимые селекторы. |
| `.nav-list a` | Ссылки внутри списка меню. |
| `.cv-layout section + section` | Секция, сразу перед которой на том же уровне находится другая секция. Так создаётся отступ между секциями без лишнего отступа перед первой. |
| `[hidden]` | Элементы с атрибутом `hidden`. |
| `a[aria-current="page"]` | Ссылка с указанным значением атрибута. |
| `:hover` | Состояние наведения указателя. |
| `:focus-visible` | Видимый фокус, в частности при управлении клавиатурой. |

### Шрифт

Два правила `@font-face` подключают обычное и жирное начертание одного Noto Serif. `font-weight: 400` — обычное, `700` — жирное. Когда HTML использует `strong`, браузер может взять настоящий жирный файл.

`font-display: swap` разрешает сначала показать текст запасным шрифтом, пока основной загружается. После загрузки весь сайт использует локальный Noto Serif. Сайт не обращается к Google Fonts.

### Переменные и наследование

В `:root` объявлены общие значения. `--color-bg` — имя переменной, а `var(--color-bg)` — её использование. Чтобы изменить основной фон, достаточно поменять одно значение в `:root`.

Даже в чёрно-белой палитре есть две основные краски, акцент и вспомогательные оттенки. Акцент — белый; создавать цветной акцент задание не требует.

`--space: 1rem` задаёт основной отступ; `--radius` — небольшое закругление кнопок. Другие размеры тоже записаны прямо и читаемо, без собственной системы вычислений.

`body` задаёт шрифт, цвет текста и высоту строки. Потомки наследуют их, если не получают своё значение. Поэтому нет необходимости повторять шрифт для каждого абзаца.

`button { font: inherit; }` просит кнопки использовать шрифт родителя вместо своего стандартного браузерного оформления. `color: inherit` работает аналогично для цвета.

### Ширина, отступы и размеры

```css
.container {
  width: 90%;
  max-width: 1120px;
  margin: 0 auto;
}
```

Контейнер занимает 90% ширины родителя, но не больше 1120 px. `margin: 0 auto` оставляет нулевые вертикальные внешние отступы и одинаковые автоматические отступы по бокам. Так содержание центрируется.

`box-sizing: border-box` включает внутренние отступы и рамки в заданную ширину. Это особенно важно для колонок 30% + 70%: их `padding` не увеличивает сумму сверх 100%.

| Свойство | Смысл в этих страницах |
| --- | --- |
| `margin` | Внешнее расстояние от элемента до соседей. |
| `padding` | Внутреннее расстояние от границы элемента до текста. |
| `gap` | Промежутки между элементами Flexbox. |
| `border` | Линия по краю; используется для монограммы, кнопок и разделителей. |
| `border-radius` | Закругление углов. |
| `font-size` | Размер букв. |
| `font-weight` | Толщина начертания. |
| `line-height` | Высота строки; безразмерное число умножается на размер шрифта элемента. |
| `text-decoration` | Подчёркивание ссылок. |
| `overflow-wrap: anywhere` | Позволяет переносить длинный email, чтобы он не раздвигал узкую колонку. |
| `display: block` | Элемент формирует блочный прямоугольник. У изображения убирает зазор текстовой строки. |
| `display: inline-block` | Позволяет оформить ссылку как кнопку с размерами и внутренними отступами. |
| `display: none` | Убирает элемент и занимаемое им место из раскладки. |
| `align-items: center` | Центрирует элементы поперёк основной оси Flexbox. |
| `justify-content: space-between` | Разносит контакты и год по краям подвала. |
| `min-height` | Минимальная высота, которая может увеличиваться при необходимости. |
| `height: auto` | Автоматическая высота; для фото сохраняет пропорции. |
| `background-size: cover` | Заполняет область картинкой с сохранением пропорций; края могут обрезаться. |
| `background-position` | Выбирает, какая часть фоновой картинки находится в заданной области. |
| `background-repeat: no-repeat` | Запрещает повторять картинку плиткой. |
| `cursor: pointer` | Показывает указатель руки на элементах управления. |
| `outline` | Рамка фокуса, не занимающая место в раскладке. |
| `position: absolute`, `top`, `left` | Размещают ссылку пропуска вне обычного потока. Для остальных основных блоков это не требуется. |
| `z-index` | Позволяет появившейся ссылке пропуска находиться поверх соседнего содержимого. |

`px` — CSS-пиксели. `%` обычно считается относительно родителя (точный смысл зависит от свойства). `rem` считается от размера шрифта корневого элемента: при стандартных 16 px значение `1.5rem` равно 24 px. Для печати используются `mm` и `pt`.

`transparent` означает прозрачность, а не дополнительную краску палитры. Например, прозрачная нижняя рамка пункта меню резервирует место; при выделении её цвет становится белым, и соседние элементы не сдвигаются.

## 7. Что меняется на телефоне

```css
@media (max-width: 768px) {
  ...
}
```

Правила внутри действуют только при ширине области просмотра до 768 CSS-пикселей включительно.

- Заголовки становятся меньше.
- При работающем JS появляется hamburger-кнопка.
- Портретная иллюстрация занимает верхнюю часть первого блока, текст идёт ниже на ровном чёрном фоне.
- Фотография с обтеканием становится уже.
- Три направления, колонки CV и части подвала располагаются сверху вниз через `flex-direction: column`.
- Колонки CV получают `width: 100%`.
- Чайный рисунок получает дополнительное место снизу, чтобы оставаться видимым.

HTML при этом не дублируется. Меняются правила отображения одних и тех же элементов. Анимаций нет, поэтому отдельно отключать движение не требуется.

## 8. Все 12 строк JavaScript

Скрипт управляет только мобильным меню. На обеих страницах одинаковое меню, поэтому его элементы всегда существуют.

```js
const navigation = document.querySelector('.site-nav');
const menuButton = document.querySelector('.menu-toggle');
const navList = document.querySelector('#nav-list');
```

`document` представляет текущую страницу. `querySelector` находит первый элемент по CSS-селектору. В переменной хранится ссылка на найденный элемент, а не копия его HTML.

`const` запрещает присвоить переменной другой объект. При этом менять свойства найденного элемента можно.

```js
navigation.classList.add('menu-ready');
menuButton.hidden = false;
```

Первая строка добавляет класс, означающий, что скрипт работает. Вторая снимает `hidden` с кнопки. На компьютере CSS всё равно скрывает эту кнопку, а на телефоне показывает.

Без JavaScript класс `menu-ready` не появится. Значит, правило скрытия мобильного списка не сработает: навигационные ссылки останутся доступными. Неактивная кнопка при этом останется скрыта.

```js
menuButton.addEventListener('click', () => {
  const isOpen = navList.classList.toggle('is-open');
  menuButton.setAttribute('aria-expanded', isOpen);
});
```

`addEventListener` регистрирует действие на событие. `click` срабатывает при обычном нажатии и при активации настоящей кнопки клавиатурой. `() => { ... }` — функция, которая будет выполнена в этот момент.

`classList.toggle` добавляет класс `is-open`, если его не было, и удаляет, если он был. Метод возвращает `true`, когда класс после операции есть, и `false`, когда его нет.

Результат записывается в `isOpen`. `setAttribute` переносит его в `aria-expanded`, чтобы видимость меню и сообщаемое состояние совпадали. Для атрибута логическое значение превращается в строку `"true"` или `"false"`.

Сам JS не рисует меню. CSS видит класс `.is-open` и применяет `display: flex` вместо `display: none`.

Печать запускается через меню браузера или Ctrl+P и не требует JavaScript.

Последнее правило `[hidden] { display: none; }` в CSS гарантирует, что наши стили кнопок не отменят скрытие элементов с этим атрибутом.

## 9. Почему CV печатается на одном листе

`print.css` подключён после основного CSS и содержит `@media print`. На обычном экране его внутренние правила не действуют. При печати они дополняют и переопределяют основные.

`@page` задаёт A4 и поля 12 mm. Цвет текста меняется на тёмный, фон страницы — на белый. У обложки и колонок фоны убираются полностью.

Шапка, навигация, подвал и ссылка пропуска скрываются: контакты уже присутствуют в самом CV.

Контейнер занимает всю полезную ширину листа. Колонки снова располагаются рядом даже при печати с узкого окна: 30% слева, 70% справа — как на экране. Фото уменьшается до 32 mm по ширине.

Основной размер текста — 9 pt, заголовки чуть крупнее, отступы компактнее. `break-inside: avoid` просит браузер не разрывать отдельные секции и записи между страницами.

Здесь нет обрезания текста через фиксированную высоту и `overflow: hidden`. В проверенном Chrome весь текущий текст помещается на одном A4. При добавлении нового содержимого нужно снова проверить предварительный просмотр. Масштаб, поля и колонтитулы, выбранные вручную в диалоге печати, тоже могут влиять на результат.

Чтобы связать видимый элемент с HTML, можно открыть страницу во встроенном браузере VS Code, включить Developer Tools и выбрать элемент инструментом инспектора. Панель Elements покажет его место в DOM и применённые стили. DOM отражает текущую структуру страницы, поэтому переход на точную строку исходного файла доступен не во всех случаях.

Для практики можно временно менять одно свойство через инструменты разработчика: выключить `float`, переключить Flexbox на колонку, изменить переменную цвета, включить класс `is-open`. Так легче увидеть причинно-следственную связь, чем заучивать строки.
