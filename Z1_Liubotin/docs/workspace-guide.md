# Третья страница: моё место у окна

Файл страницы — `pages/workspace.html`. Её правила находятся в общем `css/styles.css` под комментарием `Percent coordinates follow the image as it resizes`, а мобильные — в существующем `@media`. Изображение — `img/workspace.png`. В `js/script.js` ничего не добавлено.

## Что находится в HTML

Шапка, меню и подвал такие же, как на первых двух страницах. В меню всех трёх страниц появилась ссылка `Pracovné prostredie`. На новой странице она отмечена `aria-current="page"`.

`section` содержит главный заголовок `h1`, короткое вступление и `figure`. `figure` объединяет изображение, пять областей и подпись `figcaption`. У изображения указаны `alt` и реальные размеры 1672 × 941. CSS сохраняет пропорции и показывает рисунок чёрно-белым через `filter: grayscale(100%)`; исходный файл не изменён.

Каждая область устроена одинаково:

```html
<details name="workspace" class="hotspot" style="--x: 22%; --y: 78%">
  <summary class="hotspot-dot">3</summary>
  <div class="hotspot-panel">
    <h2>Čaj a čajová doska</h2>
    <p>Описание предмета.</p>
  </div>
</details>
```

Здесь русский текст — пояснение примера; на сайте все описания словацкие.

- `.hotspot` — одна активная область.
- `--x` и `--y` — её координаты в процентах ширины и высоты изображения.
- `summary` — заголовок раскрывающегося блока `details`: на него можно нажать мышью или пальцем. С клавиатуры: Tab, затем Enter или пробел.
- Одинаковый `name="workspace"` объединяет пять блоков: браузер разрешает открыть только один.
- `.hotspot-panel` содержит заголовок и текст.
- `.hotspot--left` добавляется двум правым точкам, чтобы их описания открывались влево и помещались на экране.

Пять областей: ноутбук, Кузя, чай и чабань, окно с видом, подоконник. Координаты отличаются, правила показа общие.

## Как точки остаются на своих местах

У `.hotspot-image` задано `position: relative`: он становится ориентиром для расположения точек. Изображение занимает `width: 100%`, а `height: auto` сохраняет его пропорции. `display: block` убирает зазор под картинкой, который бывает у строчного изображения.

На компьютере `.hotspot` получает `position: absolute`, `left: var(--x)` и `top: var(--y)`. Точка исключается из обычного потока и располагается поверх рисунка.

`transform: translate(-50%, -50%)` сдвигает точку на половину её собственной ширины и высоты. Поэтому координаты указывают на центр круга, а не на его левый верхний угол. Здесь проценты относятся к размеру самой точки, а в `left` и `top` — к размеру контейнера.

## Как описание открывается без JavaScript

```css
.hotspot-panel {
  visibility: hidden;
}

.hotspot[open] .hotspot-panel {
  visibility: visible;
}
```

При нажатии на `summary` браузер сам добавляет или убирает у `details` атрибут `open`. CSS-селектор `[open]` выбирает открытый блок и показывает его описание. JavaScript для этого не нужен.

При открытии другой точки браузер закрывает предыдущую благодаря общему `name`. Повторное нажатие на ту же точку закрывает её. Обычный Tab только переводит фокус; Enter или пробел открывают описание. Мы не зависим от получения фокуса при касании, которое отличается в Safari.

На компьютере панель располагается над точкой: `bottom: 100%`. Её ширина — `18rem`. У правых точек `right: 0` и `left: auto` привязывают правый край панели к точке. `z-index: 1` поднимает выбранную область над остальными. Всплывающая панель может закрыть часть изображения: чтобы выбрать перекрытую точку, можно закрыть текущую точку повторным нажатием либо выбрать другую через Tab и Enter.

Это упрощённый вариант принципа из учебного примера `zadanie4`. Демонстрационные переключатели ошибок и JavaScript для вычисления координат сюда не перенесены.

## Почему на телефоне панель находится под изображением

При ширине до 768 px меняются только правила расположения:

1. `.hotspot` становится `position: static`, его `transform` отключается.
2. `position: absolute` и координаты переходят на саму точку `summary`.
3. Панель теперь рассчитывает положение относительно `.hotspot-image`, поскольку промежуточный `.hotspot` больше не позиционирован.
4. `top: 100%` ставит верх панели сразу под изображением. `bottom: auto` отменяет настольное положение над точкой.
5. У всех панелей одинаковые `left: 0`, `width: 100%` и `height: 11rem`.

Обе дочерние части `.hotspot` имеют абсолютное положение, поэтому статический родитель не увеличивает высоту `figure`. Высота этого контейнера остаётся равной высоте изображения, и процентные координаты не смещаются.

`margin-bottom: 12rem` резервирует место для панели и небольшой промежуток. Панели имеют фиксированную высоту, поэтому переключение текста не двигает подвал. `overflow: auto` позволяет прокрутить описание, если оно не помещается, например при увеличении шрифта.

До выбора точки в той же области видна подпись `.hotspot-hint`. Правило `.hotspot[open] ~ .hotspot-hint` скрывает её, когда открыта любая точка. Знак `~` выбирает следующую за открытым блоком подпись с общим родителем. После закрытия точки подсказка возвращается.

Мобильная область уменьшена с 14 до 11 rem (с 224 до 176 px при базовом шрифте 16 px). Отступ внутри — 0.75rem, межстрочный интервал — 1.5. Поэтому описание занимает меньше места, но высота при переключении остаётся постоянной.

## Что изменилось в общем меню

На телефоне список меню располагается вертикально через `flex-direction: column` и `gap: 0`. Так три ссылки, включая длинное название новой страницы, помещаются на узком экране. Существующий JavaScript продолжает только открывать и закрывать меню.
