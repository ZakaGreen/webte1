# Moja online vizitka

Ilia Liubotin — WEBTE1, FEI STU, 2026/2027.

Web zatiaľ obsahuje profil a životopis. Predstavujem svoje štúdium, skúsenosti zo stáže Erasmus+ a záujmy: programovanie a AI, čajovú kultúru a investovanie. Životopis má aj štýl pre tlač na A4.

## Spustenie

Otvorte `index.html` v prehliadači. Web používa iba HTML, CSS a JavaScript, nevyžaduje inštaláciu ani zostavenie.

## Zdroje

- Fotografiu a tri ilustrácie poskytol Ilia Liubotin ako podklady pre tento web. Sú uložené v priečinku `img/`.
- Životopis a údaje o stáži vychádzajú z poskytnutého CV, certifikátu Erasmus+ a osobných informácií autora. Súkromné PDF dokumenty nie sú súčasťou webu.
- Písmo Noto Serif: Google, licencia SIL Open Font License 1.1. Lokálne súbory WOFF2 vznikli konverziou nainštalovaných TTF súborov; licenčné oznámenie je v `fonts/LICENSE.txt`.
- Monogram IL a favicon boli vytvorené pre tento web.

Pri tvorbe HTML, CSS, JavaScriptu, textov a vysvetlení som použil OpenAI Codex; obsah a kód kontrolujem a učím sa vysvetliť.

Výsledky W3C validácie týchto dvoch stránok a CSS sú v `docs/validator-html.txt` a `docs/validator-css.txt`. Podrobný výklad kódu v ruštine je v `docs/code-guide.md`.

Web zatiaľ nie je publikovaný na školskom serveri. Pred odovzdaním doplním odkaz a študijný krúžok a zmením relatívne hodnoty `og:image` na úplné URL obrázkov. Ďalšie tri stránky budú vytvorené v samostatných krokoch.
