# WEBTE1 instructions

This repository contains my university work for WEBTE1 at STU FEI.

## Main rule

Never rewrite or refactor teacher-provided code unless I explicitly ask for it.

When I ask to add or change something:
- make only the requested change;
- preserve the existing structure, syntax and coding style;
- do not rename existing variables, functions, classes or IDs;
- do not make unrelated improvements;
- if you notice another problem, mention it separately but do not fix it automatically.

## Learning goal

This is a university course project.

Prefer the simplest correct implementation that:
- satisfies the assignment;
- matches the level and style of the course lectures and practices;
- is easy for me to understand and explain during the defense.

Do not introduce unnecessary abstractions, architecture, frameworks or advanced techniques.

## Course materials

Reference materials are stored locally in `materials/`.

They include:
- the assignment;
- WEBTE1 lectures;

Use the assignment as the authoritative source for requirements.

Use lectures and existing teacher practice examples as the preferred source for implementation style and concepts.

## Communication

Explain everything to me in Russian.

Website-visible text and names required by the assignment should remain in Slovak.

Code identifiers must follow the language requirements of the assignment.

## Workflow

Do not implement future assignment steps before I ask for them.

Before making a substantial change:
1. inspect the relevant existing code;
2. explain briefly what you intend to change;
3. use the smallest necessary modification.

After a change:
1. state which files changed;
2. explain what was changed;
3. explain how it works in simple terms;
4. do not claim it works unless it was actually tested.
